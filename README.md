
# 🎯 Скарбничка цілей (GoalJar) — Telegram-бот

Простий Telegram-бот для накопичення грошей на ціль. Усе керування — кнопками, без команд.

## Можливості

- 🎯 **Нова ціль** — назва та вартість
- 💰 **Поповнити** — швидкі кнопки (+50, +100, +500 грн) або власна сума
- 📊 **Мій прогрес** — прогрес-бар `🟩🟩🟩⬜⬜⬜⬜⬜⬜⬜ 30%`, накопичено, вартість, залишок
- 📜 **Історія** — останні 10 операцій
- 🗑 **Скинути** — видалення цілі (з підтвердженням)
- Захист від некоректного вводу (текст, від'ємні числа, нуль)
- Дані зберігаються в локальному файлі `bot_data.json`

## Технології

Python 3.10–3.13, [aiogram 3.x](https://docs.aiogram.dev/)

> ⚠️ Python 3.14 і новіші можуть не працювати: для них ще немає готових збірок залежностей aiogram.

## Запуск

1. Отримайте токен у [@BotFather](https://t.me/BotFather) (команда `/newbot`).
2. Встановіть залежності:
   ```
   pip install -r requirements.txt
   ```
3. Створіть файл `.env` поруч із `bot.py` (можна скопіювати `.env.example`) і впишіть токен:
   ```
   BOT_TOKEN=123456789:ваш_токен
   ```
4. Запустіть бота:
   ```
   python bot.py
   ```
5. Відкрийте бота в Telegram і натисніть **Start**.

## Безпека

Файл `.env` додано до `.gitignore`, тож токен не потрапить на GitHub.
Ніколи не публікуйте токен. Якщо він випадково витік, відкличте його: @BotFather → `/mybots` → ваш бот → API Token → Revoke.

## Структура

```
bot.py            — увесь код бота
requirements.txt  — залежності
.env.example      — приклад файлу з токеном
.gitignore        — файли, які не потрапляють у git
```
